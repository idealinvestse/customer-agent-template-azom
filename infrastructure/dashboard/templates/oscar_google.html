Steg-för-steg-guide: Google Cloud Console (GA4, Ads & Search Console)
  1. Öppna Google Cloud Console → APIs & Services → Library och aktivera: Google Analytics Data API, Google Ads API och Google Search Console API.
  2. Konfigurera OAuth consent screen (lägg till Oscars Google-konto som Test User om appen är i Testing-läge, eller publicera internt/externt).
  3. Skapa två separata OAuth 2.0 Client IDs (Web application) för strikt isolering:
    • Klient A (GA4 & Ads): Lägg till Redirect URI {{ ga4_redirect_uri }} och klistra in GOOGLE_OAUTH_CLIENT_ID/SECRET i kort 1.
    • Klient B (GSC — endast läsning): Lägg till Redirect URI {{ gsc_redirect_uri }} och klistra in GSC_OAUTH_CLIENT_ID/SECRET i kort 2.
  4. Klicka Anslut OAuth på respektive kort. Klicka därefter Testa GSC för att hämta verifierade Search Console-properties att kopiera till NO/SE/DK.
  5. För live-läsningar i Search Console på servern krävs att AZOM_USE_MOCK=0 och AZOM_GSC_ENABLED=1 är satta i systemd/processmiljön (/opt/azom-agent/.env) — dessa flaggor kan av säkerhetsskäl inte slås på via dashboarden.
